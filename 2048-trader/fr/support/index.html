L’app reste sur l’écran de lancement

  • Forcez la fermeture de l’app puis relancez-la.
  • Vérifiez que vous avez le dernier build TestFlight ou App Store.
  • Si le problème continue, envoyez le modèle d’iPhone, la version iOS et le numéro du build.

Musique, sons ou vibrations

Les Réglages permettent de contrôler séparément Musique, Effets sonores et Vibrations. La musique respecte le mode silencieux de l’iPhone et s’arrête en arrière-plan.

Achat Trader Pro

Ouvrez Réglages → Trader Pro. Utilisez Restaurer l’achat si vous l’avez déjà acheté avec le même identifiant Apple. Trader Pro est un achat unique, sans abonnement.

Game Center

Vérifiez que Game Center est activé dans les Réglages iOS et que vous êtes connecté. Le jeu reste jouable hors ligne si Game Center est indisponible.

Réinitialiser les données locales

Réglages → Réinitialiser la progression supprime la progression, les statistiques, les réglages et les parties sauvegardées sur l’appareil. Les données Game Center et l’historique d’achat Apple sont gérés par Apple.

À propos du jeu

2048 Trader utilise un univers de marché fictif. Il ne fournit aucun conseil financier, aucune donnée de marché réelle et aucune connexion à un courtier.
